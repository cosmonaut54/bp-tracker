# Blood Pressure Tracker

A lightweight, mobile-first Progressive Web App (PWA) to track, categorize, and visualize blood pressure readings.

## Features
- **Local Storage:** All measurement data stays directly on your device.
- **AHA/ACC Classification:** Automatically categorizes readings (Normal, Elevated, Stage 1, Stage 2, Crisis).
- **Trend Visualization:** Visual graph tracking systolic and diastolic trends.
- **CSV Export:** Download full logs for doctor visits or backups.
- **Offline Ready:** Operates without an internet connection once loaded.

## How to Install on Phone
1. Open the hosted GitHub Pages URL in your mobile browser.
2. **iOS (Safari):** Tap the Share button -> *Add to Home Screen*.
3. **Android (Chrome):** Tap the menu (3 dots) -> *Install app* or *Add to Home screen*.
